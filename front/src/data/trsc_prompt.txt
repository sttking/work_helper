거래내역 조회 시 다음 사항을 고려하여 DSL을 생성해주세요:

1. 계좌 유형별 특화:
   - 수시 계좌: 기본 거래 정보 (거래일시, 은행명, 계좌번호, 거래내용, 입출구분)
   - 예적금: 기본 거래 정보 + 이자 관련 정보
   - 대출: 대출 거래금액(loan_trsc_amt), 이자금액(loan_intr_amt), 평균이자율(avg_trsc_intr_rate)
   - 증권: 주식거래유형(stock_trsc_type), 주식명(stock_nm) 포함

2. 통화 구분:
   - KRW 계좌: curr_cd = 'KRW' 필터
   - 외화 계좌: curr_cd != 'KRW' 필터, group_by에 curr_cd 포함

3. 메트릭 선택:
   - 일반 거래: total_trsc_amount
   - 대출 거래: total_loan_trsc_amt, total_loan_intr_amt, avg_trsc_intr_rate

4. 정렬 기준:
   - 거래일시 기준 내림차순 정렬 (-trsc__trsc_dt, -trsc__trsc_tm)
   - 거래금액 기준 내림차순 정렬 (-total_trsc_amount)

5. 기간 필터:
   - 기본적으로 최근 1개월 기간 설정
   - 사용자가 특정 기간을 요청한 경우 해당 기간 사용

6. 거래 유형 필터:
   - 입금/출금 구분이 명시된 경우 해당 필터 추가
   - 특정 거래내용이 언급된 경우 LIKE 필터 사용 

MAIN (공통)
1. 최대한 사용자가 물어본 바에만 대답합니다. (디폴트 제외) 
2. 디폴트 계좌 종류 = 수시        
3. 특정 통화명이 없을 시 한화(KRW)로 조회합니다.
4. 외화일 경우 group by에 curr_cd를 꼭 넣는다.

기간 정보		
1. '일주일간'과 같은 표현은 trsc_dt를 걸 때, 오늘을 포함해서 D-7, '한달전'과 같은 표현은 trsc_dt를 걸 때, 오늘을 포함해서 D-30		
2. 이번 주는 '월화수목금토일'을 포함. 예시로, 2/19(수) 기준 이번주는 2/17(월), 2/18(화), 2/19(수)를 포함		
3. '최근'은 지난 한 달간으로 정의합니다		
4. 연초는 1~3월, 연말은 10~12월을 의미합니다. 중순은 5~8월 		
5. 월초는 1~10일, 월말은 21일~말일, 중순은 11~20일을 의미합니다. 		
6. 첫주, 마지막주, 둘째주, 셋째주는 해당주의 월요일 ~ 일요일로 잡습니다.

●거래내역
1. 특정 날짜가 없을 시 오늘포함 한달치로 조회합니다.
2. 입출금 구분 없을 시 입금/출금 모두 보여줍니다.
3. 기간을 조회할시 조회된기간 내 거래내역을 모두 조회합니다.
